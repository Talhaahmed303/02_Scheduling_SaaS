## 1. Technical Standards & Industry Specifications

The architecture and data models of **Falcon Calendar** were engineered in strict conformance with the following international computing standards:

1. **RFC 5545 — Internet Calendaring and Scheduling Core Object Specification (iCalendar):**
   - Governing standard for calendar interoperability (`text/calendar`).
   - Employed in the formatting and dispatch of `VCALENDAR`, `VEVENT`, `DTSTART`, `DTEND`, and `METHOD:REQUEST` payloads generated by the mock notification dispatcher.
2. **ISO 8601 — Representation of Dates and Times:**
   - Standard governing representation of UTC timestamps and timezone offsets (`YYYY-MM-DDTHH:MM:SSZ`).
   - Strict conformance enforced across all REST API request and response envelopes.
3. **IANA Time Zone Database (Olson Database):**
   - Authoritative registry for canonical timezone nomenclature (e.g. `America/New_York`, `Europe/London`, `Asia/Karachi`, `Asia/Dubai`).
   - Integrated via Python's `pytz` and the ECMAScript `Intl.DateTimeFormat` API for client-side timezone resolution.
4. **PostgreSQL Documentation on Transaction Isolation & Explicit Locking:**
   - Section 13.3 "Explicit Locking" & `SELECT FOR UPDATE` semantics used to establish provable concurrency defense against double bookings.
5. **OpenAPI Specification 3.0.3 (OAS):**
   - Standardized API contract definition implemented via `drf-spectacular`.
